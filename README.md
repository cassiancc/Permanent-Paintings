A mod focused on making paintings a more fixed part of your environment. Pairs well with [CIT Painting Icons](https://modrinth.com/resourcepack/cit-painting-icons) and [Reliable Recipe Viewer](https://modrinth.com/mod/rrv)!

## Features

Paintings now drop the exact variant that was placed, rather than randomizing themselves.

All placeable paintings also now have dynamically generated stonecutting recipes. You can remove these recipes by tagging painting variants as `permanent_paintings:hidden_from_stonecutter`.


## Installation

Permanent Paintings is a serverside mod for 26.1 and 26.2. Its dependencies are listed below.

### Dependencies
- [MRU](https://modrinth.com/mod/mru) is required.
- [McQoy](https://modrinth.com/mod/mcqoy) or [QoMC](https://modrinth.com/mod/qomc) is recommended to configure the mod.
- [Reliable Recipe Viewer](https://modrinth.com/mod/rrv) is recommended to see recipes.
